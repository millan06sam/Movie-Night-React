# Movie Night · React Edition

M3 · Reactor Core. Rebuilding the M2 movie finder with React 19 and Vite.

## Current stage

Stage 1: three fictional sample movies rendered through App, MovieList, and MovieCard.
The cards demonstrate JSX, props, stable list keys, and conditional content.
Live search, React state, effects, and the shortlist are planned for later stages.

## Run locally

Use Node.js 24 and npm. In this folder, run:

```sh
npm install
npm run dev
```

Open the localhost URL printed by Vite. No TMDB credential is needed for this stage.

## Checks

```sh
npm run lint
npm run build
```
